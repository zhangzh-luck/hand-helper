# 航的助手 Flutter 客户端

此工程与 `web/` PWA、原 Capacitor Android 客户端及 `backend/` 分离；Android 包名为 `com.zhangzh.hangassistant.flutter`，可与原客户端共存。今日页使用 Flutter 原生组件，数据沿用现有后端 `/api/v1` 接口，不使用 WebView。

当前范围：登录、今日课程与自定义安排、课程表周视图、成绩分析、设置、手动课程增删改、深色模式、底部可拖动胶囊导航。

## 离线首页

已登录设备会在应用私有目录保存上次成功读取的今日快照（个人资料、头像、首页壁纸、当天课程和安排），并以登录会话和 API 地址隔离。断网重启时先显示缓存，不常驻展示离线横幅；写入操作会给出一次性提示。若缓存是旧日期，只沿用个人资料和壁纸，不把旧课程或安排冒充今天的数据。没有快照时仍显示首页框架和“今日数据暂不可用”及重试入口。从未登录的设备仍需先联网登录；服务器明确返回 401 时会撤销本地会话与快照。

## 课程表

课程表使用 Flutter 原生周视图：学期选择、左右翻周、节次时间轴、课程详情及手动课程编辑沿用 PWA 的数据与规则。在线成功读取后，在应用私有目录保存所有学期的完整课程实例、学期起始日、节次时间和课表背景，并以登录会话和 API 地址隔离。所选学期自动保存于当前登录会话的本机偏好，切换 Tab 或重启后恢复；学期失效时回退到当前学年或现有学期。断网时可以翻周、切学期和查看课程详情；新增、编辑、删除暂时禁用。没有缓存时明确提示课表尚未缓存，不把它误判为空课表。离线写入与同步留待整个 App 构建完成后统一实现。

## 成绩分析

分析页使用现有学期、成绩、成绩概览和 AI 历史接口；仅在用户点击生成或重新生成时调用模型分析接口。在线成功读取后按学期保存成绩、概览、AI 历史和独立的分析页壁纸。断网时仍可查看缓存的成绩详情和历史分析，但生成分析、重新生成和删除成绩暂时禁用。未缓存时显示“成绩尚未缓存”，不误显示为“暂无课程成绩”。

## 设置

设置页原生实现账号、时间、个性化、数据导入、AI 服务与关于分区。课表和成绩文件通过系统文件选择器读取，成绩先预览再确认导入；原始文件不会写入 App 快照。姓名、头像和四张壁纸首次沿用现有服务器资料，此后仅保存于应用私有目录，可离线更改，并在今日、课程表、分析、设置页统一优先显示本机版本；不再向 `/api/v1/profile` 写入，PWA 资料不会随之变化。重新登录、退出登录或服务器撤销会话时清除本机资料。头像与壁纸通过系统照片选择器选取，在本地居中裁切、压缩并预览后保存；课表和成绩导入仍使用文件选择器。外观偏好保存在本地；资料、学期和节次保存独立的离线快照，并可复用先前的今日／课表缓存。API Key 不写入快照。Android 已接入原生通行密钥登录及设置页注册、查看和移除流程，仍需真机验证；当前图片裁切为居中裁切，不具备 PWA 的手动拖拽裁切界面。iOS 工程已生成但未在 macOS 验证，使用的文件选择器要求 iOS 14 或更高版本。

设置主目录显示底部 Tab；进入任一二级页后隐藏 Tab 并释放底部空间，返回目录时恢复。个性化资料有实际未保存变更时，顶部返回和 Android 返回会询问继续编辑、放弃更改或保存并返回；单独取消图片选择以及已即时保存的外观模式不会触发提示。

## 构建与测试

```powershell
.\tool\analyze.ps1
flutter test
.\tool\build-debug-apk.ps1 -DartDefine API_BASE_URL=http://127.0.0.1:18101
```

当前 Windows Flutter SDK 的 `flutter analyze` 在项目中文路径下会因 LSP 消息长度计算错误而崩溃；上面的脚本只在分析期间创建临时英文盘符映射，结束后自动移除，不改变工程路径或运行逻辑。它会显示现有代码风格提示，但不将 `info` 级提示视为分析失败。若 Flutter 不在 `C:\flutter`，可向脚本传入 `-Flutter` 指定 `flutter.bat` 路径。

Debug APK 构建脚本会检查安装包是否包含 Material/Cupertino 图标字体；若增量构建漏打包资源，会自动 `flutter clean` 并重建，仍缺失时拒绝交付 APK。不连接本地后端时可省略 `-DartDefine`，使用默认 HTTPS API 地址。

`API_BASE_URL` 默认值为 `https://hand.zhangzh.cc`。只在连接本地开发后端时传入 HTTP 地址，并通过 `adb reverse tcp:18101 tcp:18101` 将手机回环地址转发到电脑；正式构建应使用 HTTPS。明文 HTTP 仅在 Android debug 清单中允许。

GitHub Actions 的 `Flutter iOS Release (unsigned)` 工作流可手动运行 macOS 无签名编译，上传的是 `Runner.app` 压缩包，不是可安装的 IPA。iOS 工程尚未经过 macOS 构建或真机验证，也未配置 iOS 通行密钥。

本地后端必须使用单独的测试数据库与测试账号。`127.0.0.1` 指向手机自身，不做 USB 端口转发时无法访问电脑上的服务。客户端对修改请求设置 API 同源 `Origin`，以遵循现有后端来源校验。
