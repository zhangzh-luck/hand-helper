# Third-party asset review

This repository does not yet declare a project-wide source license. Before a
public release, the maintainer must select one and verify that every bundled
asset can be redistributed under it.

## Items requiring maintainer confirmation

- `web/public/github-icons8.png`: the filename indicates a potential Icons8
  source. Record its exact source URL and license/attribution terms, then add
  the required attribution or replace it with an owned or appropriately
  licensed asset.
- `logo.png` and the app-icon derivatives under `flutter_client/`, `ios/`,
  `native_ios/`, and `web/`: confirm authorship or the applicable generation/
  redistribution terms before publishing.

## Generated and platform assets

Generated Android, Flutter, and iOS launcher/splash variants should remain
tracked only when derived from an asset the project is permitted to distribute.
System SF Symbols and platform-generated files are not a substitute for a
project license.

This file is an inventory, not a license grant or an attribution statement.
